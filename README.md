# Проект: Сетевое взаимодействие Docker-контейнеров с Java и PostgreSQL

## Описание

Этот проект демонстрирует взаимодействие между двумя Docker-контейнерами: один с базой данных PostgreSQL, другой с Java-приложением, которое выполняет CRUD-операции через REST API.

## Структура проекта

- `/src`: Главная директория, хранящая код приложения
- `Dockerfile`: Инструкции для сборки Docker-образа приложения
- `docker-compose.yml`: Конфигурация для запуска сервисов

## Запуск

1. **Запуск сервисов**:

   ```bash
   mvn clean package -DskipTests (Для более быстрой сборки)
   ```
   ```bash
   sudo docker-compose up -d --build
   ```
   
   Это запустит два контейнера: `megamarket-db` с PostgreSQL и `megamarket-back` с Java-приложением.

## Использование API

После запуска можно открыть документацию API по адресу http://localhost:8003/swagger-ui.html
